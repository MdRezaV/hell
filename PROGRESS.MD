### 🔴 Critical (App Crashes, Complete Freezes, Severe Resource Exhaustion)

1. **Main Thread Blocking & Memory Spikes in Search** (`src/main/ipc.ts`): `search-file-content` uses synchronous `readFileSync` inside a recursive directory walk, loading the full content of every non-binary file into memory. This blocks the Node.js main process event loop, freezing the entire UI and risking main process crashes on large workspaces.
2. **Watcher Ignores `.gitignore` & Polling Overhead** (`src/main/watcher.ts`): `chokidar` only ignores `.git`, watching massive folders like `node_modules` and `dist`. Combined with an aggressive 50ms `awaitWriteFinish` polling interval, this causes extreme CPU/memory spikes, I/O bottlenecks, and floods the IPC channel with events.
3. **DOM Node Explosion & Missing Virtualization** (`src/renderer/src/components/Markdown.tsx`, `src/renderer/src/components/FileExplorer.tsx`): `LinesDisplay` renders a separate DOM node for every line in code blocks, and the File Tree renders the entire directory structure without virtualization. This causes severe rendering lag, scroll jank, and massive memory consumption for large files and workspaces.

### 🟠 High (Severe UI Lag, Data Loss, Core Feature Breakage)

4. **O(N²) Markdown Re-parsing, Streaming Lag & Cache Misses** (`src/renderer/src/components/Markdown.tsx`, `src/renderer/src/utils/markdownParser.ts`): `ReactMarkdown` re-parses the entire accumulated string on every streaming token. Highlight.js auto-detection (where `autoLanguageCache` is inefficiently keyed by the full code string) and syntax re-tokenization run on every chunk, causing exponential CPU usage and UI freezing during AI streaming.
5. **State Serialization, File Tag Overwrites & Workspace Inconsistencies** (`src/renderer/src/App.tsx`): `loadWorkspaceState` hardcodes restored tags to `'PND'`. `handleNewChat` reads `fileStatesRef.current` synchronously after `setState` (saving incorrect tags), and `handleSelectChat` bypasses cleanup/double-saves. This leads to lost user state, incorrect tags, and DB/UI desync.
6. **O(N*M) Full File Tokenization & Object Allocation in Loose Match** (`src/renderer/src/utils/looseMatch.ts`): `findLooseMatch` tokenizes the entire file and uses an O(N*M) sliding window algorithm on the main thread, allocating thousands of short-lived `Token` objects. This blocks the renderer thread, pressures the garbage collector, and freezes the UI when applying replacements to large files.
7. **Unbounded, Sequential Directory Traversal & Redundant Scans** (`src/main/fsUtils.ts`, `src/main/ipc.ts`): `readDirTree` checks `isBinaryFile` sequentially (`await` in a loop) and reads 8KB of every file without concurrency limits, saturating I/O and risking file descriptor exhaustion. Furthermore, IPC handlers re-scan the entire tree and re-evaluate binary files on every call instead of caching the structure.

### 🟡 Medium (Incorrect Behavior, Moderate Performance Issues, Silent Failures)

8. **Clipboard Failures, Size Limits & Optimistic State Transitions** (`src/renderer/src/utils/PromptEngine.ts`, `src/renderer/src/App.tsx`): `buildPrompt` can generate strings exceeding OS clipboard limits. If `navigator.clipboard.writeText` fails silently (due to permissions or secure context limits), file states have already been transitioned to `'INQ'` in the DB/UI, leaving the app in an inconsistent state.
9. **Stale Caches, Unbounded Memory Growth & Ineffective Eviction** (`src/main/fsUtils.ts`, `src/renderer/src/components/Markdown.tsx`): `binaryCheckCache` and `languageFromPathCache` are never invalidated or lack eviction strategies. File type changes aren't detected until restart, and memory grows unbounded over long sessions.
10. **Race Conditions, Fire-and-Forget DB Calls & Debounce Misses** (`src/renderer/src/App.tsx`): `db:batch-set-file-states` and debounced message saves are fire-and-forget or poorly gated by refs. Rapid workspace changes or messaging can overwrite newer states or lose intermediate saves, causing data loss.
11. **False "NOT FOUND" Warnings, Stale Diff Status & Unnecessary IPC** (`src/renderer/src/components/Markdown.tsx`): `FileReplaceBlock` fails to normalize `\r\n` vs `\n` line endings and uses refs to skip re-evaluating status. Additionally, blocks trigger `useFileContent` IPC reads even when the message already provides the code content, causing incorrect "NOT FOUND" UI and wasted IPC calls.
12. **Synchronous FS Operations in IPC Handlers** (`src/main/ipc.ts`): `read-file`, `write-file`, and `delete-file` use synchronous `fs` methods (`readFileSync`, etc.) instead of `fs.promises`, blocking the main thread during file apply operations.
13. **Path Prefix Bug & Silent Fallback in `toRelative`** (`src/main/database.ts`): `startsWith` is used without checking path boundaries (e.g., `/workspace` vs `/workspace-other`). It also silently returns the full absolute path if mismatched, breaking pruning logic and leaking stale DB entries.
14. **Ineffective `memo` Comparators, Inline Callbacks & Re-renders** (`src/renderer/src/components/FileExplorer.tsx`, `src/renderer/src/App.tsx`): Custom `TreeNode` comparators always return false or run in O(N²) time. Inline callbacks and recreated scroll handlers break `memo` wrappers, causing excessive React reconciliation and GC lag.
15. **Context Provider Cascades & Inefficient Text Extraction** (`src/renderer/src/components/Markdown.tsx`): `ApplyAllProvider` creates a new context `value` object/Map on every block status change, forcing all consuming file blocks to re-render. Additionally, `extractText` recursively walks all code-block children on every render, wasting CPU cycles.
16. **Inefficient Tree Cloning & O(N²) String Concatenation** (`src/renderer/src/components/FileExplorer.tsx`, `src/main/fsUtils.ts`): Tree utilities recursively clone the entire file structure on every render/search keystroke. `formatTreeText` uses O(N²) string concatenation (`+=`) in a loop instead of an array `.join()`.
17. **Cached Rejected Promises in File Content Cache** (`src/renderer/src/utils/fileApply.ts`): `fileContentCache` stores Promises indefinitely. If an IPC read fails, the rejected Promise is cached, permanently breaking subsequent reads for that file path until manual invalidation or restart.
18. **Orphaned Chat Sessions & Inefficient Database Pruning** (`src/main/database.ts`): `chat_sessions` lacks a foreign key constraint to `workspaces`, leaving orphans on workspace deletion. `pruneWorkspaceState` fetches all states into memory and uses individual `DELETE` loops instead of batched SQL, slowing down large workspaces.
19. **Stale Directory Structure Index in Prompt Copies** (`src/renderer/src/App.tsx`): `dirStructureAddedAtIndex` becomes misaligned if the user edits, deletes, or reorders messages, causing the directory structure to be incorrectly omitted or duplicated in subsequent prompt copies.
20. **State Mutation During Render** (`src/renderer/src/components/FileExplorer.tsx`): State setters (`setPrevWorkspace`, `setTree`, `setLoading`) are called directly in the component body rather than inside `useEffect`, causing unpredictable double-rendering and React side-effect warnings.
21. **Negative Brace Depth in Tokenizer** (`src/renderer/src/utils/looseMatch.ts`): `tokenizeRegion` does not handle negative `braceDepth` for unmatched closing braces, leading to an incorrect tokenization state and potential matching failures.

### 🟢 Low (Minor UI Glitches, Micro-optimizations, Edge Cases)

22. **Permanent or Misleading Typing Indicators** (`src/renderer/src/components/AIChat.tsx`): `handleSend` shows a typing indicator while waiting for a manual "COPY" click. `handleEditSave` sets the indicator to `true` but never clears it, leaving the typing dots on screen forever.
23. **Unthrottled Concurrent IPC, Uncancelled Searches & Effect Re-runs** (`src/renderer/src/App.tsx`, `src/renderer/src/components/FileExplorer.tsx`): `latestCopyFnRef` uses unthrottled `Promise.all` for hundreds of files and re-runs its effect on every `fileStates` Map reference change. Search debounces don't cancel previous IPC calls, wasting CPU cycles.
24. **Array Index as Key in User Messages** (`src/renderer/src/components/AIChat.tsx`): `MessageBubble` uses array indices as keys for split lines (`variant.content.split('\n').map(...)`), causing visual DOM glitches when lines are added or removed during editing.
25. **Scroll Jank During Streaming** (`src/renderer/src/components/AIChat.tsx`): `scrollIntoView` is called on every message update. During rapid streaming, this forces synchronous layout recalculations on every token, causing visible scroll jank.
26. **Body Styles Leaked on Unmount** (`src/renderer/src/hooks/useResizableLayout.ts`): If the layout component unmounts while `isResizing` is true, `document.body.style.cursor` and `userSelect` are never reset, leaving the page in a permanent `col-resize` cursor with selection disabled.
27. **Stale Listeners Accumulation** (`src/renderer/src/components/Markdown.tsx`): Each `FileBlock`/`FileReplaceBlock` registers its own `file-content-invalidated` event listener via `useFileContent`. A long chat with hundreds of blocks causes listener counts to spike unnecessarily.
28. **Inefficient Date Allocations & Double Fetches** (`src/renderer/src/components/ChatHistory.tsx`): `groupByTime` creates multiple `Date` objects per session per render. Additionally, `handleDelete` fetches all sessions and then triggers a second identical fetch via `refreshKey` in the same render cycle.
29. **Pointless `setTimeout` Delay** (`src/renderer/src/components/AIChat.tsx`): `pasteAsAssistant` uses `setTimeout(..., 0)` to refocus the input, introducing an unnecessary frame delay when it could be handled synchronously or via `requestAnimationFrame`.
